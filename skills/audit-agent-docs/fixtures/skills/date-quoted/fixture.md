# Dated provenance, quoted

A comment must not carry the date it was written. This is what the rule forbids:

> The retry path was fixed after the 2026-07-02 incident, so the branch below is
> no longer reachable.

Delete the clause "fixed after the 2026-07-02 incident" and state what the code
does now.

The date is identical to the red twin. Only the quoting differs, so the rule must
stay silent.
