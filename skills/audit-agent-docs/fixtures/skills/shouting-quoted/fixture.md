# Shouting, quoted

A skill about writing has to show the writing it bans. Both examples below are
quoted, so neither counts as this file speaking:

> You must ALWAYS run the check first. Skipping it is NEVER acceptable.

Rewrite that as "run the check first" with no capitals.

The rule needs the lower-case form present too, so: a step you always run is
cheap, and a step you never run is not a step.
